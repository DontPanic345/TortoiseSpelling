# Spec-review step

Review the piece's spec and briefs as an independent reader, against the goals, the
decisions and the code. Read each brief as its build session will, with only the brief
and the code: could that session build the step and pass the Acceptance block? Check
each step's model, effort, `why` and the piece's `release` against the spec step's rules
below.

Apply every substantive finding yourself, to the spec, the briefs and the steps in
`state.json`, and leave style alone.
