# Build step

Your brief is the whole job: build what it says, to `CODING_STANDARDS.md`.

1. Build it, with the tests the brief lists.
2. Run what `CLAUDE.md`'s Checks call **done** for what you touched, including the e2e
   features your change touches.
3. Run the brief's Acceptance block. Every command exits 0.
4. Finish as "Finishing" says.

When the brief or the spec turns out wrong, correct both in your commit and say so in the
log.
